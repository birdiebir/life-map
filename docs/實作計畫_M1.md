# life-map M1 實作計畫：參考資料＋資料模型＋第一版地圖

> 執行方式：直接實作，完成後自我審查。

**Goal**：打開 `private\output\life-map.html` 就能看到世界（國家＋城市）與台灣（縣市＋368 鄉鎮）依等級上色的地圖、套組進度、回憶卡，資料來自 `private\visits.csv`（先匯入既有足跡）。

**Architecture**：`scripts\build_reference.py` 把下載的公開資料整理成 `reference\`；`lifemap\` 套件負責讀參考資料、驗證足跡、合併等級、算套組與分數；`build_map.py` 把結果和地圖、D3 內嵌成一個離線 HTML。

**Tech Stack**：Python 3.12（標準庫＋pytest）、Node（只在 build_reference 用 `Intl.DisplayNames` 產國名中文）、D3 v7、topojson-client、TopoJSON（world-atlas 50m、taiwan-atlas towns-10t）。

**Spec**：`docs\規格書_第一階段旅遊地圖.md`

## Global Constraints
- 個人資料只在 `private\`（不進 git）；程式一律經 `paths.py` 取路徑；`private.example\` 只放假資料。
- visits.csv 只存地點 ID，不存座標。
- HTML 完全離線、自包含，不用圖磚伺服器、不呼叫外部 API。
- 地點 ID：`C-<ISO3>`、`CITY-<geonameid>`、`TW-<縣市代碼>`、`TW-<鄉鎮代碼>`。
- 等級 0～5（経県値式），門檻與顏色放 `config\levels.json`。

## Review Focus
1. 使用者用 Excel 編輯後存檔的 CSV（UTF-8 BOM、CRLF）要能讀。→ Task 2 測試
2. 日期只填年、年月或空白要接受；格式錯要報出列號。→ Task 2 測試
3. 地點 ID 打錯、等級超出 0～5 時，一次列出所有錯誤列，而不是只報第一個。→ Task 2 測試
4. 未確認（confirmed=false）的足跡預設不算進地圖與分數。→ Task 3 測試
5. 地圖上沒有形狀的國家（例如科索沃）或只記到城市的足跡，仍要算進套組與分數。→ Task 3、4 測試

## 檔案結構
| 檔案 | 責任 |
|---|---|
| `paths.py` | ROOT、PRIVATE_DIR（.env `LIFEMAP_PRIVATE_DIR`）、`data_dir()`（沒有 private 就用範例並警告） |
| `lifemap\reference.py` | `Place` 資料類別、`load_places(ref_dir) -> dict[str, Place]` |
| `lifemap\data.py` | `Visit`、`Trip`、`DataError`、`load_visits(path, places)`、`load_trips(path)` |
| `lifemap\levels.py` | `ancestors(place_id, places)`、`place_levels(visits, places, include_unconfirmed=False, together_only=False) -> dict[str,int]` |
| `lifemap\sets.py` | `set_progress(sets_cfg, places, levels, min_level) -> list[dict]`、`scores(score_cfg, places, levels) -> dict[str,int]` |
| `lifemap\build.py` | `build_payload(...) -> dict`、`render_html(payload, ...) -> str` |
| `lifemap\template.html` | 地圖頁（D3） |
| `scripts\build_reference.py` | 下載資料 → `reference\` |
| `scripts\build_map.py` | CLI：產生 HTML |
| `config\levels.json`、`sets.json`、`scoring.json` | 規則 |
| `vendor\` | d3.min.js、topojson-client.min.js、授權 |

## Tasks
1. **參考資料**：build_reference.py 產出 `reference\world\countries.csv`（250 國，中文名用 Node Intl zh-Hant-TW，香港／澳門手動覆寫）、`cities.csv`（GeoNames cities15000 精簡欄位）、`city_names_zh.csv`（範例城市中文名）、`countries-50m.json`；`reference\taiwan\counties.csv`、`towns.csv`（中文名來自內政部國土測繪中心 API，因 taiwan-atlas 套件內中文名已損毀）、`taiwan-10t.json`（屬性只留代碼）。驗證：368 鄉鎮、22 縣市、代碼全部對得上。
2. **資料模型**（TDD）：load_places、load_visits（BOM／CRLF、部分日期、錯誤彙整）、load_trips。
3. **等級合併**（TDD）：直接最大值＋往上層傳遞；未確認排除；together_only。
4. **套組與分數**（TDD）：國家／地區、七大洲、22 縣市、368 鄉鎮；visited 門檻 `min_level`（預設 2，轉機不算去過）；世界分＝國家＋城市等級總和，台灣分＝縣市＋鄉鎮等級總和。
5. **地圖頁＋build_map**：世界／台灣切換、縣市／鄉鎮切換、我／一起切換、縮放、hover 提示、點擊回憶卡、套組進度條、最近足跡；用範例資料跑通（測試：HTML 產得出來、含資料）。
6. **匯入既有足跡**：寫 `private\visits.csv`、`trips.csv`（約 6 筆既有足跡＋台灣居住），產生自己的地圖。
7. **收尾**：README、開發日誌、commit。
